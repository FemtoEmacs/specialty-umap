# SF99 oracle provenance

The differential tests use the Scherliess--Fejer 1999 `VDRIFT`
implementation retained in **IRI-2020** as the oracle.

## Exact source

- **Archive:** <https://www.irimodel.org/IRI-2020/00_iri.tar>
- **Routine:** `VDRIFT`, lines 11703--12023 of `irifun.for`
- **Numerical precision:** Fortran single precision
- **Oracle size:** 450 cases
- **Generated:** 26 August 2026
- **Compiler:** GNU Fortran 16.2.0
- **Archive SHA-256:** `3d1ab8c6e37ec2bf80a805264a2d6996d6cebf6cbab6369b8f329f0ef287d2f8`
- **`irifun.for` SHA-256:** `f806f68b5924e1229a3833ac9574104a7fdfb1fa79cecef391bbc103e0e994db`

The oracle values were generated by compiling an unchanged extraction of the
official IRI-2020 routine. They therefore test the local implementation against
the archived IRI-retained SF99 implementation rather than against values
reconstructed from a plot or produced by a later model service.
