# Generated output

UMAP pages, score reports, search telemetry, and audit results are written
here. Every generated artifact must identify its manifest and random seed.

The first medical-specialty map is generated by
`specialty-specific/build-specialty-umap.lisp`. It writes:

- `specialty-umap-embedding.csv`: specialty labels, fixed x/y coordinates, and
  the eight input coordinates.
- `specialty-umap-result.sexp`: auditable parameters and coordinate array.
- `specialty-umap-clusters.sexp`: DBSCAN results computed in two-dimensional
  UMAP space, cluster feature means, descriptive names, and member specialties.
- `specialty-umap.html`: an interactive map using the persisted Common Lisp
  layout by default, with selectable feature coloring and hover details.
